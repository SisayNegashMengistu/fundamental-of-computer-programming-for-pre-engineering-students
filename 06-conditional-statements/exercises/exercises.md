# Exercises – Module 06: Conditional Statements

---

## Exercise 1: Positive, Negative, or Zero

Write a program that reads a number and prints whether it is positive, negative, or zero.

---

## Exercise 2: Leap Year Checker

Write a program that determines if a year is a leap year.

**Rules:**
- Divisible by 4 → leap year
- BUT if divisible by 100 → NOT a leap year
- UNLESS also divisible by 400 → IS a leap year

---

## Exercise 3: Electricity Bill Calculator

Write a program that calculates an electricity bill based on units consumed:

| Units Used | Rate per Unit |
|------------|--------------|
| 0 – 100    | 0.50 ETB |
| 101 – 300  | 0.75 ETB |
| Above 300  | 1.20 ETB |

---

## Exercise 4: Triangle Type

Write a program that reads three sides of a triangle and determines:
- If it forms a valid triangle (sum of any two sides > third side)
- If valid: whether it is equilateral, isosceles, or scalene

---

## Exercise 5: Switch – Month Days

Write a program using `switch` that takes a month number (1–12) and prints the number of days in that month (assume non-leap year).

---

## Exercise 6: BMI Calculator

Write a program that calculates BMI = weight(kg) / height²(m²) and classifies:

| BMI | Category |
|-----|----------|
| < 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25.0 – 29.9 | Overweight |
| ≥ 30 | Obese |
