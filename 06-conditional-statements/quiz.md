# Quiz – Module 06: Conditional Statements

---

**Q1.** Which statement executes code only when a condition is `true`?

a) `switch`  
b) `else`  
c) `if`  
d) `for`  

---

**Q2.** What is the output of this code if `x = 15`?

```cpp
if (x > 20) cout << "A";
else if (x > 10) cout << "B";
else cout << "C";
```

a) A  
b) B  
c) C  
d) Nothing
