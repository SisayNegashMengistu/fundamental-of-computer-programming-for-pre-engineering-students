# Module 06 – Conditional Statements

## Overview

Programs often need to make decisions. This module covers how to use `if`, `else if`, `else`, nested conditions, and `switch` statements to control program flow based on conditions.

## Learning Objectives

- Write `if`, `if-else`, and `if-else if-else` statements
- Nest conditional statements
- Use the `switch` statement for multi-way branching
- Use the conditional (ternary) operator `? :`
- Combine conditions using logical operators
