# Module 01 — Exercises

## Exercise 1: Hello, Me!

Modify `hello_world.cpp` to print your own name and university instead of the default message.

**Expected Output (example):**
```
Hello! My name is Sisay Negash.
I am studying at Addis Ababa University.
```

## Exercise 2: Program Info

Write a C++ program that prints the following information about itself:

```

Language: C++
Author: <Your Name>
Version: 1.0
```


## Exercise 4: Research Questions

Answer the following (short answers, 2–3 sentences each):

1. What is the difference between **source code** and **machine code**?
2. What is the role of an **IDE** in programming?
3. Why might an engineer need to learn programming?
4. What is the difference between a **compiler** and an **interpreter**?

## Challenge: About-Me Card

Create a C++ program that displays a formatted "About Me" card when run:

```
=================================
         ABOUT ME
=================================
Name   : <Your Name>
Course : Pre-Engineering
Year   : 1st Year
Hobby  : <Your Hobby>
=================================
```

> 💡 Hint: Use multiple `cout` statements. The `\n` character creates a new line (same as `endl`).
