# Quiz – Module 09: Arrays & Strings

---

**Q1.** In C++, array indices start at:

a) 1  
b) -1  
c) 0  
d) Any number  

---

**Q2.** What is the last valid index of `int arr[10]`?

a) 10  
b) 9  
c) 11  
d) 0  

---

**Q3.** What does `strlen("Hello")` return?

a) 6 (including null terminator)  
b) 5  
c) 4  
d) 0  

---

**Q4.** Which of the following declares a 2D array with 3 rows and 4 columns?

a) `int arr[4][3];`  
b) `int arr[3, 4];`  
c) `int arr[3][4];`  
d) `int arr(3)(4);`

**Q7.** What does `s.find("world")` return if "world" is not in string `s`?

a) -1  
b) 0
