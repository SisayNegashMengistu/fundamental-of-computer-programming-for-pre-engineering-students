# Module 09 – Arrays & Strings

## Overview

Arrays store multiple values of the same type under a single name. Strings are character arrays. This module covers 1D and 2D arrays, C-style strings, and `std::string`.

## Learning Objectives

- Declare, initialize, and access 1D arrays
- Iterate over arrays with loops
- Declare and use 2D arrays (matrices)
- Pass arrays to functions
- Use C-style strings and `std::string`
- Apply common string operations
