# Exercises – Module 09: Arrays & Strings

---

## Exercise 1: Array Reversal

Write a program that reads 10 integers into an array and prints them in reverse order.

---

## Exercise 2: Linear Search

Write a function `int linearSearch(int arr[], int size, int target)` that searches for `target` in `arr` and returns its index, or -1 if not found. Test it in `main()`.

---

## Exercise 3: Bubble Sort

Implement the bubble sort algorithm to sort an array of `n` integers in ascending order. Display the array before and after sorting.

---

## Exercise 4: 2D Array – Matrix Multiplication

Write a program that multiplies two 3×3 matrices A and B and stores the result in C.

**Formula:** `C[i][j] = sum over k of (A[i][k] * B[k][j])`

---

## Exercise 5: String Manipulation

Write a program that:
1. Reads a sentence from the user
2. Counts the number of words
3. Counts the number of vowels (a, e, i, o, u)
4. Reverses the string
5. Displays all results

---

## Exercise 6: Engineering – Stress Array

Read 10 stress measurements (in MPa) into an array. Then:
1. Find the maximum stress
2. Find the average stress
3. Count how many readings exceed the yield stress (input by user)
4. Print all readings that exceed the yield stress

---

Save as `exercise1.cpp` through `exercise6.cpp`.
