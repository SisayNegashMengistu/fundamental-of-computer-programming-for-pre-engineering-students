# Module 10 – Pointers

## Overview

Pointers are one of the most powerful — and initially challenging — features of C++. They provide direct access to memory addresses, enabling dynamic memory allocation and efficient array/string manipulation.

## Learning Objectives

- Explain what a pointer is and how it stores a memory address
- Declare, initialize, and dereference pointers
- Use pointer arithmetic
- Understand the relationship between pointers and arrays
- Allocate and free dynamic memory with `new` and `delete`
- Avoid common pointer errors (null pointer, dangling pointer, memory leaks)
