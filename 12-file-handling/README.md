# Module 12 – File Handling

## Overview

Programs often need to store data permanently. This module covers reading from and writing to files using C++ `fstream` streams.

## Learning Objectives

- Open, read, write, and close files using `fstream`
- Use `ofstream` for output (writing) and `ifstream` for input (reading)
- Detect end-of-file (EOF)
- Handle file open errors
- Append to existing files
- Read and write structured data (structs) to files
