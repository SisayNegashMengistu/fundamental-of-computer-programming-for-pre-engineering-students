# Exercises – Module 12: File Handling

---

## Exercise 1: Student Grade File

Write a program that:
1. Asks the user for 5 students' names and grades
2. Writes them to `grades.txt` (one per line, space-separated)
3. Reads the file back and calculates the class average

---

## Exercise 2: Append Log

Write a program that appends a user-entered message with a timestamp to `activity_log.txt`. Run it multiple times to see entries accumulate.

---

## Exercise 3: Word Counter

Write a program that reads a text file (`input.txt`) and counts:
- Total number of lines
- Total number of words
- Total number of characters

---

## Exercise 4: Sensor Data Analysis

Create `sensor_data.txt` with 10 temperature values (one per line). Write a program that reads the file and reports:
- Minimum temperature
- Maximum temperature
- Average temperature
- Number of readings above 30°C

---

## Exercise 5: Copy File

Write a program that copies the contents of `source.txt` to `destination.txt` line by line.

---

## Submission

Save as `exercise1.cpp` through `exercise5.cpp`. Include sample input files (e.g., `input.txt`, `sensor_data.txt`) with your submission.
