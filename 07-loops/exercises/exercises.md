# Exercises – Module 07: Loops

---

## Exercise 1: Factorial

Write a program that reads an integer `n` from the user and calculates `n!` (n factorial).

**Example:** `5! = 1 × 2 × 3 × 4 × 5 = 120`

---

## Exercise 2: Fibonacci Sequence

Write a program that prints the first `n` Fibonacci numbers.

**Example (n=8):** `0  1  1  2  3  5  8  13`

---

## Exercise 3: Sum of Even Numbers

Write a program that sums all even numbers from 1 to `n` (input by user).

---

## Exercise 4: Prime Number Checker

Write a program that reads an integer and checks whether it is prime.

**Hint:** A number `n` is prime if it has no divisors other than 1 and itself. Test divisibility from 2 to `sqrt(n)`.

---

## Exercise 5: do-while Menu

Write a program with a menu system using a `do-while` loop:

```
=== Unit Converter Menu ===
1. Meters to Feet
2. Kilograms to Pounds
3. Celsius to Fahrenheit
4. Exit
Enter choice:
```

The menu repeats until the user selects 4 (Exit).

---

## Exercise 6: Numerical Integration

Write a program that approximates the area under the curve `f(x) = x²` from `x = 0` to `x = 1` using the Trapezoidal Rule with `n = 1000` intervals.

**Expected result:** approximately `0.3333`

---

## Exercise 7: Pattern Printing

Print the following pattern using nested loops (for `n = 5`):

```
*
* *
* * *
* * * *
* * * * *
```
