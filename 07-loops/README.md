# Module 07 – Loops

## Overview

Loops allow programs to repeat code without writing it multiple times. This module covers `for`, `while`, and `do-while` loops, nested loops, and loop control with `break` and `continue`.

## Learning Objectives

- Write `for`, `while`, and `do-while` loops
- Choose the right loop type for a given problem
- Use `break` to exit a loop early
- Use `continue` to skip an iteration
- Write and understand nested loops
- Apply loops to engineering calculations
