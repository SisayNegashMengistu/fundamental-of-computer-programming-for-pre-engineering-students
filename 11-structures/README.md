# Module 11 – Structures

## Overview

Structures (`struct`) group related variables of different types under one name. They are the building blocks for organizing real-world data in C++.

## Learning Objectives

- Declare and use `struct` types
- Access struct members with `.` and `->` operators
- Create arrays of structures
- Pass structures to functions by value and by reference
- Use nested structures
- Understand `typedef` and struct aliases
