## 📚 About This Repository

This repository is a comprehensive, open-source educational resource designed for **first-year pre-engineering students** who are learning programming for the first time. It uses **C++ as the primary teaching language** and covers foundational concepts progressively — from "What is a program?" all the way through object-oriented design.

Every module includes:
- 📖 Clear lesson notes in Markdown
- 💻 Commented C++ example programs
- 🏋️ Exercises and practice problems
- 📝 Quiz questions and review activities
- 🎯 Expected outputs for all examples

## 🚀 Getting Started

### Prerequisites

- A C++ compiler:  
  - **Windows**: [MinGW-w64](https://www.mingw-w64.org/) or [MSVC](https://visualstudio.microsoft.com/)  
  - **Linux/macOS**: `g++` (usually pre-installed — check with `g++ --version`)
- A text editor or IDE:  
  - [VS Code](https://code.visualstudio.com/) (recommended for beginners)  
  - [Code::Blocks](http://www.codeblocks.org/)  
  - [Dev-C++](https://www.bloodshed.net/)

### Compiling a C++ Example

```bash
# Navigate to a module folder
cd 01-Introduction-to-Programming

# Compile the example
g++ -o hello hello_world.cpp

# Run it
./hello          # Linux/macOS
hello.exe        # Windows
```

## 📋 Module Overview

| # | Module | Key Topics |
|---|--------|-----------|
| 01 | Introduction to Programming | What is programming? History, IDE setup |
| 02 | Problem Solving | Computational thinking, decomposition |
| 03 | Algorithms & Flowcharts | Pseudocode, flowchart symbols |
| 04 | Variables & Data Types | `int`, `float`, `char`, `bool`, constants |
| 05 | Operators & Expressions | Arithmetic, relational, logical, bitwise |
| 06 | Input & Output | `cin`, `cout`, formatting |
| 07 | Conditional Statements | `if`, `else`, `switch` |
| 08 | Loops | `for`, `while`, `do-while`, nested loops |
| 09 | Functions | Declaration, definition, scope, recursion |
| 10 | Arrays & Strings | 1D/2D arrays, C-strings, `std::string` |
| 11 | Pointers & Memory | Address-of, dereferencing, dynamic memory |
| 12 | Structures | `struct`, `typedef`, nested structures |
| 13 | File Handling | `fstream`, reading/writing files |
| 14 | OOP Fundamentals | Classes, objects, constructors, inheritance |
| 15 | Debugging | Syntax/logic errors, debugging strategies |
| 16 | Practical Challenges | Mini-projects and capstone problems |
