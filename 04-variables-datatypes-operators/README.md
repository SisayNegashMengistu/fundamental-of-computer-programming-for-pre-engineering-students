# Module 04 – Variables, Data Types & Operators

## Overview

Variables are the building blocks of any program. This module covers how to declare variables, the different data types available in C++, and how to perform calculations using operators.

## Learning Objectives

- Declare and initialize variables in C++
- Identify and use fundamental data types (`int`, `double`, `char`, `bool`, `float`)
- Understand type modifiers (`short`, `long`, `unsigned`)
- Apply arithmetic, relational, logical, assignment, and increment operators
- Understand operator precedence and type casting
