# Exercises – Module 01: Introduction to Programming

Complete the following exercises after reading the lesson. Each exercise builds on the concepts introduced in this module.

---

## Exercise 1: Write Your First Program

**Task:** Write a C++ program that prints your name and your university department on two separate lines.

**Expected output (example):**
```
Name: Sisay Negash
Department: Pre-Engineering
```

**Hints:**
- Use `cout` and `endl`
- Remember to include `<iostream>` and `using namespace std;`

---

## Exercise 2: Program Information Card

**Task:** Write a program that displays the following information about itself:

```
Program Name : Introduction to C++
Author       : [Your Name]
Version      : 1.0
Date         : [Today's Date]
```

## Exercise 3: Engineering Context

**Task:** A civil engineering student wants to print a simple banner for a structural analysis program. Write a C++ program that displays:

```
========================================
   STRUCTURAL ANALYSIS PROGRAM v1.0
   Department of Civil Engineering
========================================
```

## Exercise 4: Identify the Error

The following program contains a syntax error. Find and fix it, then explain what was wrong.

```cpp
#include <iostream>
using namespace std

int main() {
    cout << "Hello Engineer!" << endl
    return 0;
}
```

**What errors do you see? List all of them.**

---

## Exercise 5: Reflection Questions

Answer the following questions in a comment block inside a `.cpp` file:

1. What is the purpose of `#include <iostream>`?
2. What does `int main()` mean?
3. What happens if you forget `return 0;`?
4. What is the difference between a compiled and an interpreted language?
5. List three real-world examples where C++ programs are used in engineering.
