# Module 01 – Introduction to Programming

## Overview

This module introduces the fundamental concepts of computer programming, the history of computing, and how computers process instructions. By the end of this module you will understand what programming is, why it matters, and how the software development lifecycle works.

## Learning Objectives

- Define programming and explain its purpose
- Describe the history and evolution of programming languages
- Explain how a computer executes a program
- Identify the main steps in the software development process
- Distinguish between compiled and interpreted languages

## Prerequisites

None – this is the starting point!
