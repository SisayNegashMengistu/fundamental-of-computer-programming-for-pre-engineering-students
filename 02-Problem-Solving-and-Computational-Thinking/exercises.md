# Module 02 — Exercises

## Exercise 1: Decomposition

**Problem:** A university cafeteria wants to calculate the total cost of a student's meal.  
Use decomposition to list the sub-problems, then write pseudocode for the solution.

---

## Exercise 2: Pattern Recognition

Identify the pattern in the following and write a **generalized** pseudocode:
- Area of a square: `side²`
- Area of a circle: `π × r²`
- Area of a triangle: `½ × base × height`

What common pattern do you see? How would you design a function for each?

---

## Exercise 3: Write Pseudocode

Write pseudocode for:
1. Reading 10 numbers and printing only those greater than their average
2. Checking if a year is a leap year (divisible by 4, not by 100, or divisible by 400)
3. Counting how many characters in a sentence are vowels

---

## Exercise 4: Computational Thinking in Real Life

Pick **one** real-world engineering problem and describe it using the four pillars:
- **Decomposition**: How do you break it down?
- **Pattern Recognition**: What patterns do you notice?
- **Abstraction**: What details can be hidden?
- **Algorithm**: Write a high-level solution algorithm

Example topics: water flow in pipes, traffic light control, GPS routing.

## Challenge: Algorithm Design Contest

Design an algorithm (pseudocode + flowchart description) to solve:

> "Given a list of N exam scores, find the highest, lowest, and average score, and count how many students passed (score ≥ 60)."

Include:
1. Input/output specification
2. Pseudocode
3. Description of the flowchart (or draw it)
