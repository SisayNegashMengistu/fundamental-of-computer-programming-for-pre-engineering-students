## Guidelines

1. **Read the project description completely** before starting
2. **Design your solution first** using pseudocode or a flowchart
3. **Write code incrementally** — compile and test as you go
4. **Handle edge cases** (invalid input, empty files, etc.)
5. **Use functions** — each major task should be its own function
6. **Add comments** explaining your design decisions

## How to Submit

- Place your project file in this folder
- Include a short `README_yourname.txt` explaining what the program does and how to run it
