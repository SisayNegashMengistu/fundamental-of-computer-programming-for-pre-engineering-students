# Module 05 – Input & Output

## Overview

This module covers how C++ programs interact with the user through the keyboard and screen. You will learn to use `cin`, `cout`, and `<iomanip>` to create clean, professional-looking output.

## Contents

## Learning Objectives

- Use `cout` to display formatted output
- Use `cin` to read user input
- Use `getline()` to read full lines
- Apply `<iomanip>` manipulators for formatting
- Use escape sequences in strings
- Understand basic `printf`/`scanf` for C-style I/O
