## Exercise 1: Pseudocode – Temperature Conversion

Write pseudocode (not C++ code) to convert a temperature from Celsius to Fahrenheit.

**Formula:** `F = (C × 9/5) + 32`

Your pseudocode should:
1. Accept a Celsius temperature as input
2. Calculate the Fahrenheit equivalent
3. Display the result

## Exercise 2: Flowchart – Pass or Fail

Draw a flowchart (on paper or using a tool like draw.io) that:
1. Reads a student's exam score (0–100)

## Exercise 4: Translate Pseudocode to C++

Translate the following pseudocode into a working C++ program:

```
START
  INPUT radius
  SET area = 3.14159 * radius * radius
  OUTPUT "Area of circle = ", area
END
```

## Exercise 5: Engineering Problem – Ohm's Law

**Problem:** Write pseudocode AND a C++ program to calculate the resistance in an electrical circuit using Ohm's Law.

**Formula:** `R = V / I`

Where:
- `V` = voltage in Volts
- `I` = current in Amperes
- `R` = resistance in Ohms

Your program should:
1. Ask the user for voltage and current
2. Calculate the resistance
3. Display the result with appropriate units
