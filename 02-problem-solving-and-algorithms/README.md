# Module 02 – Problem Solving & Algorithms

## Overview

Before writing a single line of code, good programmers think carefully about the problem and plan a solution. This module introduces **computational thinking**, **pseudocode**, and **flowcharts** — essential tools for designing algorithms before coding them in C++.

## Learning Objectives

- Define an algorithm and explain its properties
- Apply computational thinking: decomposition, pattern recognition, abstraction, algorithmic thinking
- Write pseudocode to describe a solution
- Draw flowcharts using standard symbols
- Translate pseudocode/flowcharts into C++ programs
