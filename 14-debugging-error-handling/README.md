# Module 14 – Debugging & Error Handling

## Overview

Every programmer makes mistakes. This module teaches systematic strategies for finding, understanding, and fixing errors in C++ programs.

## Contents

| File | Description |
|------|-------------|
| [lesson.md](lesson.md) | Full lesson |
| [examples/](examples/) | Buggy and fixed code examples |
| [exercises/](exercises/) | Practice problems |
| [quiz.md](quiz.md) | Knowledge-check questions |

## Learning Objectives

- Distinguish between syntax, runtime, and logic errors
- Use compiler warnings effectively
- Apply print-statement debugging and systematic testing
- Use `assert()` for internal consistency checks
- Handle runtime errors with `try`, `catch`, and `throw`
- Use `cerr` for error output
- Understand common bugs and how to avoid them
