# Quiz – Module 08: Functions

---

**Q1.** A function prototype is:

a) The function body  
b) A declaration that tells the compiler the function's name, return type, and parameters  
c) A call to the function  
d) A `#define` macro

**Q2.** What is the return type of a function that does not return a value?

a) `int`  
b) `null`  
c) `void`  
d) `none`

**Q3.** In pass by **reference**, what happens when the function modifies its parameter?

a) The original variable is unchanged  
b) The original variable is also changed

d) A copy is returned

**Q4.** Which symbol denotes a reference parameter?
