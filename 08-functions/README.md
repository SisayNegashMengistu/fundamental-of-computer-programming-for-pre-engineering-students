# Module 08 – Functions

## Overview

Functions allow you to organize code into reusable, named blocks. This module covers how to declare, define, and call functions, as well as parameter passing, return values, and recursion.

## Learning Objectives

- Declare and define functions in C++
- Distinguish between function declaration (prototype) and definition
- Pass arguments by value and by reference
- Return values from functions
- Understand scope and lifetime of variables
- Write recursive functions
- Understand function overloading
