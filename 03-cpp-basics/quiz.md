# Quiz – Module 03: C++ Basics & Program Structure

---

**Q1.** Which preprocessor directive includes a standard library header?

a) `#define`  
b) `#include`  
c) `#pragma`  
d) `#namespace`  

---

**Q2.** What does `#define PI 3.14159` do?

a) Creates a variable named PI  
b) Replaces every occurrence of PI in the code with 3.14159 before compilation  
c) Imports a math library  
d) Declares a function  

---

**Q3.** The purpose of `using namespace std;` is:

a) To create a new namespace  
b) To import all standard library functions into the global scope, avoiding `std::` prefix  
c) To define the main function  
d) To link external libraries

**Q4.** In the compilation pipeline, which step comes immediately after preprocessing?

a) Linking  
b) Execution  
c) Compiling

**Q5.** Which comment style is used for multiple lines in C++?

a) `// comment`  
b) `# comment`  
c) `<!-- comment -->`  
d) `/* comment */`

a) Enables optimization  
b) Enables all warning messages  
c) Links wall libraries

**Q7.** Which header file provides mathematical functions like `sqrt()` and `pow()`?

**Q9.** What value should `main()` return to indicate the program ran successfully?

a) 1  
b) -1
