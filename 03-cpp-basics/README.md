# Module 03 – C++ Basics & Program Structure

## Overview

This module covers the structure of a C++ program in detail. You will learn how programs are compiled, how to use comments, and how the compiler processes your source code.

## Learning Objectives

- Describe the structure of a C++ program
- Use preprocessor directives (`#include`, `#define`)
- Understand namespaces
- Write single-line and multi-line comments
- Understand the compilation process (preprocessing → compiling → linking → executing)
- Use basic compiler flags with `g++`
