# Module 13 – OOP Fundamentals

## Overview

Object-Oriented Programming (OOP) is a programming paradigm that organizes code around **objects** that combine data and behavior. This module introduces classes, objects, encapsulation, constructors, and inheritance.

## Learning Objectives

- Understand the difference between a class and an object
- Define member variables and member functions
- Use access modifiers: `public`, `private`, `protected`
- Write constructors and destructors
- Implement encapsulation with getters and setters
- Understand inheritance (base and derived classes)
- Understand the concept of polymorphism (introductory)
